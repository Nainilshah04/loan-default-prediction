## 📊 Project Objective
Predict loan default risk using machine learning to help financial institutions minimize losses and optimize lending decisions.

## 🎯 Business Problem
- **Problem:** 10-15% of loans default, causing significant financial losses
- **Solution:** Build a predictive model to identify high-risk customers before loan approval
- **Impact:** Reduce default rate by 20-30% through data-driven decision making

## 🔧 Tools & Technologies
- **Python:** pandas 3.0, scikit-learn 1.8, matplotlib, seaborn
- **SQL:** SQLite/PostgreSQL for data exploration
- **Power BI:** Interactive business dashboard
- **ML Models:** Logistic Regression, Random Forest, XGBoost

## 📁 Dataset
- **Source:** Kaggle
- **Target:** Binary classification (Default = 1, Paid = 0)

## 🚀 Project Pipeline
1. ✅ **Project Setup** - Environment, dependencies, Git initialized
2. ⏳ **SQL Analysis** - Exploratory queries to identify risk patterns
3. ⏳ **Python EDA** - Data cleaning, visualization, feature engineering
4. ⏳ **ML Modeling** - Classification models with ROC-AUC evaluation
5. ⏳ **Power BI Dashboard** - Business metrics visualization
6. ⏳ **Business Report** - Actionable insights and recommendations
